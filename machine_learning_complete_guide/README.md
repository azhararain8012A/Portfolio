# Complete Machine Learning Workflow

A portfolio-level educational project covering the complete supervised machine-learning lifecycle.

## Topics Covered

1. Problem definition and target selection
2. Dataset loading and inspection
3. Exploratory data analysis concepts
4. Data quality and preprocessing
5. Feature engineering
6. Train/test splitting and stratification
7. Baseline models
8. Logistic Regression
9. Random Forest
10. Gradient Boosting
11. Cross-validation
12. Hyperparameter tuning with GridSearchCV
13. Accuracy, precision, recall and F1-score
14. Confusion matrix
15. ROC-AUC
16. Model comparison
17. Model persistence with Joblib
18. Prediction on new samples
19. Reproducibility and leakage prevention

## Run

```bash
pip install numpy pandas scikit-learn joblib
python machine_learning_complete_guide.py
```

The example uses scikit-learn's built-in Breast Cancer dataset, so no external CSV download is required.

## Why this project matters

The goal is not just to train one classifier. It demonstrates how a real ML workflow moves from raw problem definition to a validated, tuned and saved model that can later be integrated into an application or API.

## Tech Stack

Python, NumPy, Pandas, Scikit-learn, Joblib

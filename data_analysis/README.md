# Data Cleaning & Analysis Scripts

A practical Pandas project showing a complete data-cleaning workflow on an intentionally messy sales dataset.

## Workflow

- Load raw CSV data
- Standardize column names and text
- Convert numeric fields safely
- Handle missing values
- Remove duplicate rows
- Filter invalid negative quantities
- Create a calculated `sales` metric
- Analyze sales by category
- Export a cleaned CSV

## Run

```bash
pip install pandas
python data_cleaning_analysis.py
```

Output: `sample_sales_cleaned.csv`

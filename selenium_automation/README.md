# Selenium Automation Practice

Portfolio-ready Selenium browser automation using the public Quotes to Scrape demo.

## Demonstrates

- Headless Chrome automation
- Multi-page navigation
- CSS selectors
- Structured data extraction
- CSV export
- Safe browser cleanup

## Run

```bash
pip install selenium
python selenium_automation_practice.py
```

The script extracts pages 1–3 and creates `quotes_output.csv`.
